# ZarishHealth requests for comments

An RFC records a decision that is too large for an architecture decision record: a change to the
protocol, the data model, or the way repositories fit together. Numbers are never reused.

## Proposals

No RFC has been merged yet.

## Writing one

1. Copy [the template](0000-template.md) to `text/NNNN-<kebab-title>.md`, using the next free
   number.
2. Open a pull request. The discussion happens there.
3. Once merged, the number is spent: a withdrawn proposal keeps its number and gains a
   `Withdrawn` status.
